Bienvenido

Este sitio ha sido diseñado utilizando CSS Grid para la estructura general y Flexbox para los componentes internos. Su objetivo es enseñar cómo combinar ambas tecnologías de diseño modernas.

A medida que navegues por las páginas, observarás cómo se integran las técnicas de diseño responsivo, adaptándose automáticamente a distintos tamaños de pantalla.

Diseño Moderno

Usamos rejillas flexibles y componentes reutilizables.

Adaptabilidad

El diseño se ajusta automáticamente al dispositivo.

Optimización

Código limpio, semántico y fácil de mantener.
